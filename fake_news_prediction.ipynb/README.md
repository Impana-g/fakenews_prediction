# Fake News Prediction

## About the Project
Fake News Prediction is a machine learning project that aims to classify news articles as **Fake News** or **Real News** using text data and natural language processing techniques.

## Objectives
- Explore and preprocess a news dataset.
- Clean and prepare text for machine learning.
- Convert text into numerical features using TF-IDF.
- Train a machine learning classification model.
- Evaluate model performance using suitable metrics.
- Predict whether a given news article is likely to be fake or real.

## Technologies Used
- Python
- Jupyter Notebook
- Pandas and NumPy
- Scikit-learn
- Natural Language Processing (NLP)
- TF-IDF Vectorization
- Matplotlib and Seaborn

## Getting Started

### 1. Clone the repository

```bash
git clone https://github.com/Impana-g/fakenews_prediction.git
cd fakenews_prediction
```

### 2. Install the dependencies

```bash
python -m pip install pandas numpy scikit-learn matplotlib seaborn jupyter ipykernel
```

### 3. Open the notebook

Open `fake_news_prediction.ipynb` in Visual Studio Code with the Python and Jupyter extensions installed. Select a Python kernel and run the notebook cells in order.
